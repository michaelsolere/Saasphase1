## Variante : Hybride — Pilotage quotidien + file d’actions dense

### Intention
Combiner les deux directions retenues : la structure claire du « Pilotage quotidien » (en-tête compact, alerte de situation, onglets métier) avec la file d’actions dense du « Poste de travail » (échéance, état, priorité, action dans chaque ligne).

### Choix principaux
- **Onglet par défaut : Aujourd’hui** — file d’actions triée (urgence puis échéance) avec action directe dans la ligne, plus un panneau « Repères » réduit au contexte utile.
- **Alerte de situation** en haut de page : ce qui bloque ou attend avant la fin de journée.
- **Onglets** : Aujourd’hui, Planning, Mise-bas, Poids & croissance, Mère, Historique.
- **Planning** : tableau compact ; modèles, séries et configuration regroupés derrière un détail replié.
- **Poids & croissance** : sous-onglets internes — Saisie du jour (grille de saisie intégrée dans la page, sans fenêtre), Courbes (moyenne + mini-courbes par animal), Indicateurs descriptifs, Tableau détaillé, Comparaison entre portées, Ajustements tracés.
- **Historique unifié** : un seul fil pour mesures, soins, mise-bas et observations.
- **Interactions** : onglets et sous-onglets, saisie groupée avec compteur de progression, terminaison directe d’une tâche, raccourcis vers planning/historique, toasts.

### Arbitrages
- **Fort** : première écran court et actionnable ; le reste reste exploré à la demande ; reprend le langage visuel du Parcours adoptant.
- **Faible** : une seule portée affichée à la fois (le changement se fait via le sélecteur) ; la comparaison multi-portées reste une page séparée.
- **À surveiller** : garder l’onglet Aujourd’hui court même quand la file s’allonge.

### Meilleur usage
Le pilotage quotidien d’une portée active avec des actions à traiter vite, sans perdre la profondeur historique.
