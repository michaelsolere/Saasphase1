## Variante : Chronologie de portée

### Intention
Faire de l’âge de la portée le repère principal. La bande J0 → J+13 permet de se situer immédiatement, puis la chronologie regroupe les événements et les jalons.

### Choix principaux
- **Bande d’âge** : J0, J3, J5, J7, J9, J11, J+12, prochaine échéance.
- **Chronologie par défaut** : mise-bas, observations, soins, pesées et échéances dans un seul fil.
- **Onglets** : Chronologie, Aujourd’hui, Observations, Historique.
- **Détails latéraux** : repères rapides, planning et accès directs sans répéter toutes les données.
- **Interactions** : positionnement sur un jour, filtre de l’historique, actions directement dans l’événement.

### Arbitrages
- **Fort** : très bon repère temporel et bonne compréhension de l’histoire de la portée.
- **Faible** : moins adapté à une longue liste de tâches à traiter ; l’utilisateur peut devoir remonter dans la chronologie.
- **À surveiller** : garder les tâches du jour toujours visibles, même si la chronologie devient longue.

### Meilleur usage
Le suivi longitudinal d’une portée, les échanges avec le vétérinaire ou la relecture des événements après coup.
