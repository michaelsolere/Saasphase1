## Variante : Poste de travail dense

### Intention
Réduire les répétitions grâce à une colonne persistante : les portées suivies à gauche, puis les sections de la portée sélectionnée. Le contenu principal devient une file d’actions.

### Choix principaux
- **Rail des portées** : changer de portée sans perdre le contexte ni remonter la page.
- **Navigation interne** : À traiter, Planning, Mise-bas, Poids, Mère, Historique.
- **Vue opérateur** : tableau dense avec échéance, état, priorité et action directement dans la ligne.
- **Configuration repliée** : modèles, séries et jalons isolés sont accessibles sans occuper le premier écran.
- **Interactions** : changement de portée, changement de vue, terminaison directe d’une tâche, panneau de configuration extensible.

### Arbitrages
- **Fort** : excellent pour une utilisation fréquente et plusieurs portées actives.
- **Faible** : plus “outil de gestion” et moins chaleureux ; la colonne persistante prend de la place sur petit écran.
- **À surveiller** : sur mobile, le rail doit devenir une rangée horizontale compacte ou un sélecteur.

### Meilleur usage
Un élevage qui alterne souvent entre plusieurs portées et veut traiter une file d’actions plutôt que lire un dossier complet.
