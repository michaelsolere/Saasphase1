## Variante : Pilotage quotidien

### Intention
Reprendre le modèle du Parcours adoptant : un en-tête compact, une alerte de situation, la prochaine action visible, puis des onglets métier.

### Choix principaux
- **Aperçu par défaut** : uniquement les actions du jour, les repères de portée et l’activité récente.
- **Onglets** : Aperçu, Soins & jalons, Mise-bas, Poids & croissance, Mère, Historique.
- **Densité** : faible à moyenne ; les sections secondaires quittent le flux principal.
- **Progressive disclosure** : configuration du planning derrière un bouton/détail, historique dans son propre onglet.
- **Interactions** : changement d’onglet, validation d’une tâche, raccourcis d’action et toasts.

### Arbitrages
- **Fort** : très lisible, bon point d’entrée quotidien, facile à expliquer.
- **Faible** : l’utilisateur voit une seule portée à la fois ; la comparaison de plusieurs portées reste une action séparée.
- **À surveiller** : ne pas transformer chaque onglet en une nouvelle page très longue.

### Meilleur usage
Le suivi quotidien d’une portée active, notamment après la mise-bas, avec une action prioritaire à traiter rapidement.
